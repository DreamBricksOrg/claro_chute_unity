# Projeto Claro

## ⚠️ Requisitos Importantes

### Versão da Unity
- **Versão Exata Requerida:** Unity 2021.3.45f1
- ⚠️ **ATENÇÃO:** Esta versão específica é OBRIGATÓRIA para o funcionamento correto do Kinect
- NÃO atualize ou mude a versão da Unity, pois isso pode comprometer a compatibilidade com o Kinect

### Kinect
- Este projeto utiliza o sensor Kinect para rastreamento de movimento
- A integração foi testada e validada especificamente com a Unity 2021.3.45f1
- Qualquer alteração na versão da Unity pode resultar em incompatibilidade com o Kinect

## Configuração do Projeto
1. Certifique-se de ter instalado a Unity versão 2021.3.45f1
2. Não atualize a versão do projeto quando solicitado
3. Mantenha todas as dependências e pacotes nas versões especificadas

## Solução de Problemas
Se você encontrar problemas com o Kinect:
1. Verifique se está usando exatamente a Unity 2021.3.45f1
2. Confirme se não houve atualizações automáticas da Unity
3. Em caso de dúvidas, reverta para a versão 2021.3.45f1

## Observações Adicionais
- Mantenha o Unity Hub configurado para não atualizar automaticamente este projeto
- Faça backup do projeto antes de qualquer modificação
- Documente qualquer alteração necessária no projeto
